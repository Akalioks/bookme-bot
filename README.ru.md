# BookMe: бот для записи клиентов

Telegram-бот для записи в барбершоп или салон: клиент выбирает услугу, мастера, день и время. Бот напоминает о визите, а владелец управляет записями прямо в Telegram.

Сам бот на английском, потому что он для международного портфолио. Все тексты лежат в `bot/texts.py`.

## Что умеет

**Клиент**
- Записаться: услуга → мастер (или «любой свободный») → день → время → подтверждение.
- Оставить телефон одной кнопкой. Бот запоминает его, и при следующей записи не спрашивает.
- «My bookings»: посмотреть свои записи и отменить любую с подтверждением.
- Получить напоминания за 24 часа и за 2 часа до визита, с кнопкой «не смогу прийти».

**Владелец** (`/admin`)
- Расписание на сегодня, завтра или любой день, с именами и телефонами клиентов.
- Отмена записи. Клиент автоматически получает уведомление.
- Уведомление о каждой новой записи и об отмене записи клиентом.
- Статистика: записи и ожидаемая выручка на 7 дней, итоги за 30 дней, топ услуг.
- Рассылка всем клиентам, с предпросмотром перед отправкой.
- Выгрузка всех записей в CSV, файл открывается в Excel.

**Надёжность**
- Двойная запись невозможна: перед сохранением бот повторно проверяет, свободно ли время.
- Если бота перезапустили, пока клиент записывался, бот просто предлагает начать заново, а не ломается.
- Напоминания не дублируются после перезапуска, потому что их статус хранится в базе.

## Демо-режим (для портфолио)

`DEMO_MODE=true`: любой посетитель может открыть `/admin` и посмотреть панель владельца. При этом он видит **только свои** записи, а рассылка уходит **только ему**. Так потенциальный клиент может попробовать обе стороны бота, и при этом не увидит чужие имена и телефоны.

Для настоящего заказчика ставьте `DEMO_MODE=false` и укажите его ID в `ADMIN_IDS`.

## Запуск на своём компьютере

1. В Telegram откройте **@BotFather**, отправьте `/newbot` и скопируйте токен.
2. Узнайте свой ID у **@userinfobot**.
3. В папке проекта выполните эти команды (PowerShell):

```powershell
python -m venv .venv
```
```powershell
.venv\Scripts\pip install -r requirements.txt
```
```powershell
copy .env.example .env
```

4. Откройте `.env` и вставьте токен в `BOT_TOKEN`, а свой ID в `ADMIN_IDS`.
5. Запустите бота:

```powershell
.venv\Scripts\python -m bot
```

Бот работает, пока открыто окно. При первом запуске он создаёт базу `bookme.db` с примерами: 4 услуги, 2 мастера. Поменять их можно в функции `seed_demo_data` в `bot/repo.py`, а потом удалить `bookme.db`.

> Токен — это пароль от бота. Не показывайте его никому и не загружайте `.env` на GitHub. Файл `.gitignore` уже это предотвращает.

## Тесты

```powershell
.venv\Scripts\pip install -r requirements-dev.txt
```
```powershell
.venv\Scripts\python -m pytest
```

13 тестов прогоняют диалоги целиком через поддельный Telegram: запись, занятое время, двойную запись, отмену, перезапуск, панель владельца, демо-режим и напоминания.

## Чтобы бот работал круглосуточно

Нужен сервер, ваш компьютер для этого не подходит. Варианты:
- **VPS**: готовая конфигурация для сервера (Docker Compose + Caddy, все боты вместе) лежит в папке `deploy`, инструкция в `deploy/README.md`. Для одного бота: `docker build -t bookme .`, затем `docker run -d --env-file .env -e DATABASE_URL=sqlite+aiosqlite:////app/data/bookme.db -v bookme-data:/app/data --restart always bookme`. Строка `-e DATABASE_URL=...` нужна, иначе путь к базе из `.env` уведёт её мимо тома, и база сотрётся при пересборке.
- **Railway или Render**: подключить репозиторий с GitHub и добавить переменные из `.env` в настройках.

## Вход в веб-панель администратора

Бот подтверждает вход в веб-панель ([admin-dashboard](../admin-dashboard)). Панель показывает ссылку вида `t.me/<бот>?start=login_<код>`. Бот спрашивает «Log in to the admin panel?» с кнопками Confirm и Cancel и отмечает ответ в таблице `web_logins`. Ссылка действует 5 минут, код: `bot/handlers/weblogin.py`.

## Структура

```
bot/
  __main__.py      запуск, команды меню, фоновые напоминания
  app.py           сборка диспетчера, регистрация пользователей
  config.py        настройки из .env
  db.py            таблицы: users, services, masters, bookings
  repo.py          все запросы к базе и демо-данные
  slots.py         расчёт свободного времени (чистая логика)
  texts.py         все тексты бота
  keyboards.py     все кнопки
  reminders.py     напоминания 24 ч / 2 ч
  handlers/
    user.py        /start, About, My bookings, отмена
    booking.py     процесс записи
    admin.py       панель владельца
tests/             тесты
```
